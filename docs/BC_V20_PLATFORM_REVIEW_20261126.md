**公开逐条预测已经确认的问题**

1. B 的验证集有 1,679 条，其中一根轴承占 1,515 条（90.23%）。与历史 v18 的最终公开预测相比，v20 在该轴承的 RMSE 降低约 0.56%，另两根分别恶化约 9.69% 和 9.08%。两版实验序列不同，这不是单独某一算法的因果对照，但说明“总体 RMSE 略降”不能作为跨设备泛化已改善的证据。
2. C 的 v20 公开集 NASA 惩罚约 97.45% 来自最严重的 1% 样本，FD004 分组贡献约 97.03%。约 97.53% 的惩罚来自低估方向。NASA 虽然对相同幅度的高估惩罚更重，也不能据此推断本次大分数主要来自高估。隐藏集的方向尚未知。
3. 当前 `regression/evaluation.py` 的晋升门槛只约束总体 RMSE 和 MAE；NASA、分设备最差误差和尾部误差只作记录。此前 B 的候选保留依据偏重总体 RMSE，未阻止小分组退化；C 的整体误差与 NASA 尾部也未共同验收。

**下一轮筛选应调整的四项**

1. B 按整根轴承和寿命段同时验收，保留总体主指标改善要求；对设备平均、最差设备和 MAE 的退化设置明确拒绝条件。低估权重 1.25 重新作为研究候选，不能因公开总体小幅下降就认定成功。截图未提供实际采用方案，不能将隐藏集退步直接归因给这一项。
2. C 同时检查 RMSE、NASA、P99 绝对误差，以及高估/低估各自的惩罚贡献。先处理可解释的极端残差，不能统一上调或下调全部预测，也不改变原始寿命标签。
3. 仅用合法输入检验工况差异和修正机制。公开 meta 仅用于分组诊断，不进入预测；新增分组、缩放或修正参数仅用 train 拟合。保留实际父权重、Adam、scaler 和可核验继承。
4. 用可取得的授权阶段或整设备公开评估验证收益，明确与正式阶段的区别。通过整体、分组及尾部检查后，再做十轮与新镜像验收。固定数据的确定性重复不能充当独立泛化证据。
