# 正式测评前四项优化实施记录

2026 年 11 月 26 日。

已实施 A 完整专家包续训、控制器按当前实验条件整理历史、重复预测与数据读取优化、C 独立续训菜单。SDK 1.0.4、标准训练预测入口、两阶段模型调用和原有晋升门槛继续使用。

**实施内容**

| 调整 | 结果 |
| --- | --- |
| A 完整包续训 | 非路由实验保留父辅助专家与冻结路由，独立导出全部组件和清单。逐 epoch 选择与早停比较完整预测器，辅助专家文件摘要保持不变。 |
| 控制器证据 | `experiment_evidence` 按父模型、train、validation、方案与执行策略区分历史条件，单列当前尝试和拒绝次数，缺失身份不会被当成同条件失败。 |
| 计算效率 | 关闭特征修正时四、五传感器网络各预测一次；数据解析复用首行结构与路径，同时逐行校验结构、数值、ID、标签。A 严格输入校验与读取合并为一次解析。 |
| C 独立菜单 | 只为 C 追加 `fine_rate`：MSE、学习率 3e-5、最多 8 epoch、全参数续训。B 原菜单与所有原门槛保持原值。 |

显式 `frozen_router` 仍重新训练各专家并在最后校准完整路由，报告保留主组件 epoch 曲线的原范围。完整预测器逐 epoch 选版适用于路由父模型的非路由续训路径。
