## 加载与复现

在交付目录执行：

```powershell
docker load -i gas-rsi-abc-wyx-sdk104-v7-20261123.tar
docker run --rm --network none --read-only gas-rsi-abc:wyx-sdk104-v7-20261123 describe
```

正式平台入口仍为 `python3 /app/harness.py describe|train|predict`，模型身份、父产物和数据投影由平台提供。不要独立启动 train 后等待 stdin 结束。

离线镜像重测：

```powershell
.\.venv\Scripts\python.exe -B -X utf8 scripts/validate_multitask.py `
  --baseline-root 'D:\liyue\工业模型赛题研究' `
  --output runtime/my-v7-offline-run --rounds 4 `
  --image gas-rsi-abc:wyx-sdk104-v7-20261123 --docker-context desktop-linux
```
